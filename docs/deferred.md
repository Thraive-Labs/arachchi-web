# Deferred Features


Do not build any of these in the MVP. Document each as "deferred" in the relevant code if a placeholder is needed.

- Multi-language / i18n content (code is i18n-ready, content is English-only)
- Multi-currency (code stores prices in cents with currency field, only CAD at launch)
- Algolia / Meilisearch (Postgres FTS is enough)
- Personalized / collaborative-filtering recommendations (basic recs are in MVP - see Section 11)
- Reviews and ratings system
- Loyalty program / points
- Referral program
- Gift cards
- Pre-orders
- Abandoned cart email recovery sequence
- Live chat
- 3D / AR product views
- Native mobile apps
- Cloudflare in front of Vercel
- Upstash Redis
- Klaviyo / marketing automation
- Cloudinary
- BigQuery analytics warehouse
- A/B testing infrastructure
- AI-based size recommendation
- Social commerce integrations (Instagram Shopping, TikTok Shop)
- Ambassador / affiliate tracking
- "Currently viewing" or fake-urgency UI patterns

When demand for one is shown by data, add it as its own focused project.
